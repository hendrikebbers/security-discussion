# Security Policy

This repository is part of [Hiero](https://hiero.org), a project of
[LF Decentralized Trust](https://www.lfdecentralizedtrust.org). It is maintained by a community
of maintainers and is **not** part of any bug bounty program. No bounty is paid for reports.

## Our security support level

**Level 0 – Best effort, upstream only**

- We only provide security fixes upstream (main branch / next release).
- We do not guarantee to respond to security reports.
- We do not provide fixes for older versions.

## Reporting a vulnerability

<!-- Level 0: keep this paragraph. Level 1+: replace it with a pointer to the section above. -->
If you want to make us aware of a vulnerability, please contact the maintainers privately via
<channel, e.g. GitHub private vulnerability reporting or email>. Please understand that we
cannot guarantee a response or a fix.

A good report contains the affected version, a description of the impact and a proof of
concept or exact steps to reproduce.

## Do not disclose vulnerabilities in public

Never report security vulnerabilities in public GitHub issues, pull requests, pull request
comments, discussions, Discord or any other public channel.

Public content that contains vulnerability or exploit details will be removed. The reporter
will be contacted and pointed to the correct channel. Repeated public disclosure after a
warning can lead to the account being blocked from the Hiero GitHub organization.

## AI-generated reports

You are welcome to use AI tools in your research. You are not welcome to forward their output
without validating it.

Reports that are generated by AI tools and not verified by the reporter **will be closed
without further review and without a response**. This includes reports that

- do not contain a proof of concept or exact steps to reproduce,
- describe theoretical issues without showing that they can be reached in the code,
- do not reference the affected version or code, or
- show signs of being generic AI output that the reporter has not understood.

Repeated submission of such reports can lead to the account being blocked.
