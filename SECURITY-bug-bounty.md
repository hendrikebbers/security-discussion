# Security Policy

This repository is part of [Hiero](https://hiero.org), a project of
[LF Decentralized Trust](https://www.lfdecentralizedtrust.org), and is covered by the
**[Hedera Bug Bounty Program](https://immunefi.com/bug-bounty/hedera/)** on Immunefi.

## Reporting a vulnerability

**Please report all security vulnerabilities through the
[Hedera Bug Bounty Program on Immunefi](https://immunefi.com/bug-bounty/hedera/).**

The maintainers of this repository have decided to handle all security reports exclusively
through the Hedera Bug Bounty Program. This is the only channel through which reports for this
repository are reviewed and through which bounties are paid. Please read the program's scope,
rules and requirements before submitting. A proof of concept that demonstrates a real,
reproducible impact is required.

Following this decision, GitHub private vulnerability reporting (GitHub Security Advisories)
is **disabled** for this repository. Reports sent through other channels may not be reviewed.

### Submission fee and fee waiver

Immunefi may charge a submission fee for researchers who have not yet built a reputation on
the platform. This fee protects the security team from spam and unvalidated reports.

If you have found a vulnerability but cannot pay the fee, please contact
<security contact, e.g. hiero-prodsec@lists.lfdecentralizedtrust.org> **without including any
vulnerability details**. Briefly describe who you are and in which component you found the
issue. The security team can grant a limited number of fee-free submissions.

## Do not disclose vulnerabilities in public

Never report security vulnerabilities in public GitHub issues, pull requests, pull request
comments, discussions, Discord or any other public channel.

Public content that contains vulnerability or exploit details will be removed. The reporter
will be contacted and pointed to the correct channel. Repeated public disclosure after a
warning can lead to the account being blocked from the Hiero GitHub organization.

## AI-generated reports

You are welcome to use AI tools in your research. You are not welcome to forward their output
without validating it.

Reports that are generated by AI tools and not verified by the reporter **will be closed
without further review and without a response**. This includes reports that

- do not contain a working proof of concept,
- describe theoretical issues without showing that they can be reached in the code,
- do not reference the affected version or code, or
- show signs of being generic AI output that the reporter has not understood.

Repeated submission of such reports can lead to the account being blocked.

## What you can expect

Every valid report submitted through the bug bounty program is triaged by Immunefi and
reviewed by the security team. Reviews happen in private and can take time, especially
because of the high volume of incoming reports. Please do not ask for status updates in public
channels.

## Security team, embargo list and CVEs

The Hiero security team, the embargo list for operators of networks built on Hiero, and the
handling of CVEs are described in the
[Hiero organization-wide security policy](https://github.com/hiero-ledger/.github/blob/main/SECURITY.md).
For general questions (never vulnerability details), contact the
[Hiero security team](mailto:hiero-prodsec@lists.lfdecentralizedtrust.org).
